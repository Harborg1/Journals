#Setting up the app as a web server
1. Install Firebase CLI  
   Run the following command:
   npm install -g firebase-tools

2. Install the FlutterFire CLI  
   Run:
   dart pub global activate flutterfire_cli

   If needed, add this to your system PATH:
   C:\Users\<your-username>\AppData\Local\Pub\Cache\bin

3. Login to Firebase  
   Run:
   firebase login

4. Configure Firebase for your Flutter app  
   In your Flutter project directory, run:
   flutterfire configure
der er ikke 
   - Select platforms (web, android, etc.)
   - This generates a file: lib/firebase_options.dart

5. Update your main.dart file  
   Import the options file:
   import 'firebase_options.dart';

   And update Firebase initialization:
   await Firebase.initializeApp(
     options: DefaultFirebaseOptions.currentPlatform,
   );

6. Run the command flutter build web

7. Run firebase deploy to deploy the website. A URL link for the website will then be given to you 
   so you can access your web-application.
